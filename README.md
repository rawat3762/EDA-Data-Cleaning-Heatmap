# EDA-Data-Cleaning-Heatmap

## Project Description
This project performs Exploratory Data Analysis (EDA) on a CSV dataset. It analyzes missing (null) values, calculates their percentage, visualizes them using a heatmap, and cleans the dataset by removing columns and rows containing null values.

## Features
- Load CSV dataset
- Analyze missing (null) values
- Calculate percentage of null values
- Visualize missing data using heatmap
- Remove columns with high null values
- Clean dataset using dropna()

## Tools & Libraries
- Python
- Pandas
- Seaborn
- Matplotlib

## Project Steps
1. Import dataset
2. Check null values
3. Calculate null value percentage
4. Visualize missing values using heatmap
5. Remove column with many null values
6. Remove rows containing null values
7. Clean dataset for further analysis
